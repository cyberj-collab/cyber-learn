# Cyber-Learn

A free, beginner-friendly website for people exploring a career in cybersecurity.

**Live site:** https://cyberj-collab.github.io/cyber-learn/

## What's inside

| Page | What it covers |
|---|---|
| Start Here | A suggested learning order for total beginners |
| Is Cyber for Me? | A no-pressure self-check that maps interests to roles |
| Explore Roles | SOC, penetration testing, GRC, cloud security, DFIR and AppSec |
| Try a Mission | Three five-minute, fictional exercises (phishing, log review, account security) |
| Roadmap | Free resources and optional certifications, by stage |
| Labs | Free and free-tier practice platforms, sorted by level |
| Practice Legally | Where and how it's legal to practice |
| Getting Hired | Resume, LinkedIn, networking and interview tips |
| Glossary | Searchable plain-English definitions |

## How it's built

- Plain HTML, CSS and a small amount of vanilla JavaScript. No frameworks, build step or trackers.
- One shared stylesheet (`assets/style.css`) with light and dark themes.
- Accessible by design: skip link, keyboard focus styles, semantic headings, reduced-motion support.
- Mobile-friendly navigation and responsive tables.
- Hosted free on GitHub Pages.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
