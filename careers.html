Careers

Explore Careers

Cybersecurity is not one job. It is a family of roles that protect systems, data, and people. Use these profiles to explore which path fits you. They are a starting point, not a verdict.

About pay: The U.S. Bureau of Labor Statistics (BLS) reports a national median wage of about $129,180 per year (May 2025) for Information Security Analysts. That figure is a benchmark for the whole occupation across all experience levels. It is not the pay for each role below, and it is not an entry-level estimate. Pay varies widely by location, experience, employer, and role. Source: BLS Occupational Outlook Handbook: Information Security Analysts.

1. SOC Analyst (Security Operations Center)

  • What you doYou watch security alerts, investigate suspicious activity in logs, sort real threats from false alarms, and escalate incidents.
  • Typical dayYou triage alerts in a SIEM (a tool that collects and searches logs), check suspicious emails and logins, write short incident notes, and hand off shifts.
  • Skills to buildNetworking basics, Windows and Linux logs, phishing analysis, and a SIEM tool such as Splunk or Microsoft Sentinel.
  • Example entry routeOne possible route is IT support, then a junior SOC role. Internships and other routes also exist.
  • Helpful certsCompTIA Security+, CompTIA CySA+, BTL1, Splunk Core Certified User (general Splunk search skills), and Microsoft Certified: Security Operations Analyst Associate (exam SC-200).

2. Penetration Tester (Ethical Hacker)

  • What you doWith written permission, you attack systems the way a real attacker would, then report the weaknesses so they can be fixed.
  • Typical dayYou scope tests, scan and exploit systems in authorized environments, document your findings, and write client reports.
  • Skills to buildNetworking, Linux, web applications, scripting in Python or Bash, and clear report writing.
  • Example entry routeIT, SOC, or system administration experience, plus a strong record of hands-on lab work. It is rarely a first job.
  • Helpful certsCompTIA PenTest+, eJPT, and OSCP (advanced).
  • ImportantOnly test systems you have written permission to test, and stay within the agreed scope. Even on infrastructure you own, check that your provider's terms allow testing.

3. GRC Analyst (Governance, Risk, and Compliance)

  • What you doYou help an organization follow security frameworks and laws, assess risk, and write policies.
  • Typical dayYou map controls to frameworks such as NIST and ISO 27001, prepare for audits, review vendor risk, and update policies.
  • Skills to buildSecurity frameworks, risk assessment, documentation, and communication.
  • Example entry routeAudit, compliance, IT, or business roles. It is a great fit for strong writers and organizers, and it is less hands-on technically.
  • Helpful certsISC2 CC (entry level), CompTIA Security+, and ISACA CISA, which is for later in your career because certification requires qualifying professional experience. Passing the exam alone does not make you certified. See the CISA requirements.

4. Cloud Security Engineer

  • What you doYou secure systems that run in AWS, Azure, or Google Cloud, including identities, networks, and configurations.
  • Typical dayYou review cloud permissions, fix misconfigurations, automate security checks, and work with developers.
  • Skills to buildCloud fundamentals, identity and access management, networking, and scripting or infrastructure as code.
  • Example entry routeSystems administration, cloud support, or a SOC role, then cloud security.
  • Helpful certsAWS Certified Security – Specialty, Microsoft Certified: Cloud and AI Security Engineer Associate (which replaced AZ-500, retired August 31, 2026), and CCSK.

5. DFIR Analyst (Digital Forensics and Incident Response)

  • What you doAfter a breach, you figure out what happened, how far it spread, and how to recover.
  • Typical dayYou collect and analyze disk, memory, and log evidence, build timelines, and support recovery.
  • Skills to buildOperating system internals, log analysis, forensic tools, and careful documentation.
  • Example entry routeA SOC analyst role, then incident response.
  • Helpful certsCySA+, GIAC GCIH, and GIAC GCFA (advanced).

6. Application Security (AppSec) Engineer

  • What you doYou help developers build secure software by finding and fixing vulnerabilities in code and applications.
  • Typical dayYou review code, run security scanners, do threat modeling, and teach developers secure coding.
  • Skills to buildProgramming, web application vulnerabilities such as the OWASP Top 10, and secure design.
  • Example entry routeSoftware development, then AppSec.
  • Certifications and learning resourcesHands-on skills usually matter more than certs here. GIAC GWAPT is one certification option. The free OWASP learning resources are another place to start, though they are not a certification.

Which path might fit you?

  • You like solving puzzles under time pressure: SOC or DFIR.
  • You like breaking things to make them stronger: Penetration testing.
  • You like writing, organizing, and big-picture thinking: GRC.
  • You like building and automating: Cloud security or AppSec.

Exploratory only. You can switch paths, and many professionals do.
