Hands-On Labs Directory

Reading about security only gets you so far. These platforms let you practice real skills in safe, legal environments built for learning. Everything below is sorted by level, and each entry says what it costs so you can start free.

Cost key: Free means fully free. Free tier means a solid free option, with paid plans for more content. Prices change, so check each site's official page before you pay for anything.

Before You Start

  • Read our Where It's Legal to Practice page first.
  • You don't need an expensive computer. Many of these run in a web browser, but some need extra setup. Each entry says what it needs.
  • Pick one beginner platform and stick with it for a few weeks before adding another.

Level 1: Total Beginner

Start here if you're new to computers, networking, or the command line.

Platform What you'll learn Cost
TryHackMe Guided rooms covering networking, Linux, and web basics. Many rooms are free; some full paths need a subscription, and free in-browser lab time is limited. Needs a free account. Free tier
OverTheWire: Bandit Linux command-line skills through short puzzle levels. You connect with SSH (a remote terminal tool built into most computers). Free
Cisco Packet Tracer Build and troubleshoot virtual networks (routers, switches, IP addressing). It's software you install, and you'll need a free Cisco Networking Academy account. Free
picoCTF Beginner capture-the-flag puzzles from Carnegie Mellon University, with a practice area that's always open. Free

Level 2: Building Skills

Start here once you're comfortable with basic Linux commands and networking ideas.

Platform What you'll learn Cost

Build Your Own Home Lab

A home lab is a safe, isolated set of practice machines that you own. It's also a great thing to talk about in job interviews.

What you need

  • A computer with enough memory to run a few virtual machines at once. How much you need depends on which machines you run, so check each one's requirements.
  • VirtualBox: free software that runs virtual machines.

Good starter machines

  • Kali Linux: a security toolkit operating system. Use it as your "attacker" machine.
  • OWASP Juice Shop: a deliberately insecure web shop for practicing web attacks.
  • Metasploitable 2: a deliberately vulnerable Linux machine from Rapid7. Download it from the link in Rapid7's official guide.

Keep it safe

  • Put vulnerable machines on a dedicated internal network in VirtualBox, so they can only talk to your other lab machines.
  • Don't give vulnerable machines a second network adapter (such as NAT or bridged), and turn off shared folders and shared clipboard for them.
  • Avoid host-only networking for vulnerable machines. It still lets them talk to your own computer.
  • Never expose a deliberately vulnerable machine to the internet.

Suggested First Month

  1. Week 1: OverTheWire Bandit, levels 0–10.
  2. Week 2: TryHackMe Pre Security path (free rooms).
  3. Week 3: Build one network in Packet Tracer.
  4. Week 4: Hack The Box Starting Point, Tier 0.

Keep short notes on what you learned each week. Those notes become your portfolio.
